# Waoo CRM

Custom CRM for **Waoo Party LLC** (Katy / Houston, TX) to replace HoneyBook: clients, events, calendar, quotes, contracts with e-signature, invoices, payments (Stripe + Zelle), a client portal, and SMS/email notifications.
