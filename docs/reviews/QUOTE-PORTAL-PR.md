Previously an owner could preserve a draft quote but could not show its exact PDF privately or carry the accepted discount into finance. This adds an immutable presentation and private PDF, quote-only expiring grants, and explicit client accept/reject evidence. Explicit owner conversion copies the accepted money and service labels into finance; verified net ledger receipts and ordinary staff/equipment/transport/short-notice checks still determine whether resources can be confirmed. An accepted quote neither takes payment nor guarantees capacity.

Legacy event tokens retain codec v1. Quote tokens use v2 bound to the immutable revision and cannot access payments, contract or details. Revision invalidation affects only previous quote grants; recovery returns the same active link. Client serializers omit private notes, discount reasons/approvers, route evidence and recipes. PDF external fetch/PHP/JS is disabled and output escaped. Both client outcomes freeze separate versioned consent text; default configuration is empty. An administrator cannot decide through a client session.

Grant→event→quote locking serializes competing decisions and revocation; owner preparation/revision locks owner→sorted existing quote grants→event→quote. One conversion per event/accepted offer is protected under current row reads, aggregate versions and unique constraints. Same-intent retries preserve the original evidence without another decision/audit or agreement. Audit/crypto/artifact failures do not commit partial links or decisions. A filesystem write followed by a database rollback can leave an unreachable private artifact; there is no public file URL and no artifact cleanup job in this increment.

The finance bridge preserves accepted subtotal/travel/discount/final/deposit and original labels even after catalog edits. Address/detail-only correction may create a new source financial revision while retaining accepted money; changes to customer, time, services/recipes/characters/outfits or travel amount reject for the separate change/requote flow. Contract commercial lines show the discount while legal terms remain unchanged. Card fee behavior is unchanged; no Affirm or real Stripe call.
