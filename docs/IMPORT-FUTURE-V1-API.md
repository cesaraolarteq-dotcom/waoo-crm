## Explicit domain commit B

Optional `remember_mapping` defaultfalse; source package/characters mapping suggestions never auto-apply. Do not accept browser amounts, dates, source IDs, notes, contract signature evidence or client fields overriding CSV. Mapping current PriceVersions provides operational recipe only; historical amounts stay exactly source.

Unique durable `imported_project_links` keyed by SHA256 exact source project ID, one event/customer/current immutable imported revision +version/domain-intent hash. Immutable `imported_project_revisions` freezes source24/safe normalized source/mapping/event version/file hash and source row metadata. Separate immutable `imported_ledger_lines` carry source=honeybook, signed cents, original method and received_date only (no fabricated received_at or test Stripe/Zelle ledger row). Only current imported revision contributes to its source-money projection; older revisions remain history, never added twice.

Create customer only on explicit choice; existing customer must match displayed version and is never overwritten. SaveEventDraft builds audited operational selections, original event times/address/travel, owner-entered setup/breakdown. Import scope uses metadata-only audit (IDs/hashes/counts, not source/client values), including nested customer/event saves; restore normal audit after exceptions. Private source snapshots live in domain records, not log entries. Commit is one transaction with customer/event/link/revision/ledger/mapping/receipt/audit; no resources/portal/contract/communication/charge. Any failure rolls back all new domain writes.

Stable receipt replay returns original linkage before dynamic state checks; same source+mapping/customer intent under another UUID/batch also reuses the original project without another client/event/ledger. Changed source or mapping requires explicit existing `expected_import_version` and `expected_event_version`, and can update only its linked draft without reservations/contracts/new CRM ledger. This creates a new imported revision and switches current pointer, never edits old money. Confirmed/signed events reject for CHANGE/reconciliation; no silent overwrite. Saved mappings keyed by exact source services+characters, versioned suggestions only. GET `/admin/api/imports/honeybook/{batch}/rows/{row}/mapping` reads that private staged row and returns `{suggestion:ImportServiceMapping|null}`; never put raw source values in query strings or access logs.
