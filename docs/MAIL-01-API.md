## Storage and safety

`outbound_messages`: immutable event/customer/financial source binding, displayed event/customer versions, template key/version/locale/hash, channel=email, environment=sandbox, recipient hash, intent SHA256(unique), due_at, grant_id nullable, created_by and **encrypted hidden payload** (recipient, rendered subject/HTML/plain text, source fingerprint). No raw tokens/recipient/body in queue jobs, audit or exception chains. Source business snapshots stay in their existing tables. `outbound_message_states`: one mutable projection/message, integer version, scheduled/dispatching/sent/delivered/bounced/complained/blocked/skipped/delivery_unknown, attempt_count, stable error code, provider ID/hash and timestamps. `outbound_message_events`: immutable deduplicated transitions (metadata only, no provider raw payload). `event_message_policies`: one/event, pause boolean/version/actor. No mutable delivery status on the immutable intent. Restrictive FKs, dependent down order, no guessed delivery.

Default-off sandbox_mail + local/testing/staging only. Owner reads/writes require fresh active owner+confirmed2FA, staging HTTPS/secure session, normal CSRF/no-store/throttle. Worker repeats environment/feature/actor, exact allow-list membership and current source checks. mail_allowlist config defaults[], must be valid email addresses of existing active enrolled owner admins (no browser substitution). Actual transport binding defaults unavailable; no SMTP/mail log/HTTP call. Test fake transport is explicitly injected, never shipping credentials or enabling an env flag.

Approved copy config `waoo.mail_templates` defaults[]: key → locale → `{version,approval_reference,subject,paragraphs,button:{label,variable}|null,closing,required_variables}`. A nonempty approval reference is evidence supplied through reviewed configuration, not proof manufactured by the app. No stock approvals or source text seeded. Strict declared placeholder set; required values cannot be omitted/unknown; subjects no CRLF and <=60 Unicode chars (fail closed, never silently edit approved copy). Frozen HTML layout from reviewed #69 and matching plain text; exactly one optional server URL, no raw client HTML/attachments/tracking. Frozen current config hash rechecked at dispatch; missing/revoked/changed approval blocks. Subject formatting fixes from #69 still required before approval of actual text. Invoice-like totals derive current immutable finance/actual net ledger, never browser money or private discount reasons. Source imported HoneyBook events excluded pending cutover communication contract.

## First business adapter: three essential reminders

`PlanEventMail::execute(User,int eventId,array $input,string $key): array`; POST `/admin/api/events/{event}/mail/reminders`, required displayed expected_event_version/expected_customer_version, portal_grant_id (same event/customer, active nonquote grant with event.read; balance also pay.create), optional templates subset of balance_reminder/week_before/thank_you_review (default all3). No input recipient/body/amount/date/URL. Pins latest finance matching displayed event version and source state; event must be capacity_reserved and not imported. Same owner UUID+intent returns original message IDs, even after state changes; altered UUID intent409. Unique business intent prevents duplicates across owners/UUIDs; changed customer/finance/event/recipient/template requires explicit new planning, keeps old history.

Due times: week_before seven Houston calendar days before party start; balance_reminder24h before the immutable finance balance_due_at (due itself24h before party), only positive current balance; thank_you_review next Houston calendar day at the event's local end time (explicit foundation timing, no invented9am schedule). Future reminders only; no retroactive catch-up. Review link must be explicitly configured as an allowed HTTPS URL, no sample default. Portal link is server-built from the supplied active encrypted grant, never issued/rotated by planning; grant must outlive due_at and current access is checked again at dispatch. If a required source/copy/link/timing is unavailable, whole planning transaction fails, not a made-up zero/sent state. No automatic hook from approval/payment in this foundation.

`PauseEventMail::execute(User,int eventId,array $input,string $key): array`; PATCH `/admin/api/events/{event}/mail/policy` `{expected_version,paused:bool}` (first version0). Event→policy locks and owner audit; stale409, UUID retry stable. Pausing doesn't delete history; due messages stay scheduled while paused. Unpause doesn't resurrect skipped stale messages or permit late sends.

## Jobs/transport/delivery protocol

`DispatchOutboundMail::execute(int messageId): void`; queued `DispatchOutboundMailJob` serializes ID only, tries1. Bounded CLI `waoo:mail-due --limit=50` selects due scheduled messages, enqueues IDs, no installed cron. No future/body secrets in job or logs. Claim lock order existing grant→event→customer→policy→message state; recheck pinned versions, current money/recipient/grant/template, event not cancelled/rescheduled, still appropriate balance, pause and exact allow-list. Stale source → skipped; missing/config/recipient/transport → blocked; paused → remain scheduled. All refusal/audit transactions atomic. Guard once more immediately before transport; the contract does not promise to revoke an already claimed external request instantaneously.

Claim commits dispatching+attempt event before the external boundary. Another worker/duplicate ID sees dispatching and never sends. `MailTransport::send(OutboundEnvelope): TransportReceipt` is an injectable interface; default DisabledMailTransport fails before any send. Concrete provider adapter is NOT implemented here. A fake-only successful receipt yields sent (not delivered). Any uncertainty/crash after claim stays delivery_unknown/dispatching for reconciliation, **no automatic retry** without a verified provider reconciliation contract; no fictional provider idempotency header or guarantee of exactly-once external delivery. Persisted intent/event history survives.

`RecordMailDelivery::execute(string provider,string providerMessageId,string providerEventId,string outcome,CarbonImmutable occurredAt): void` is an internal seam for a future authenticated adapter, not a public webhook/owner action. Supported delivered/bounced/complained; dedup exact provider event, binding mismatch409, never downgrade terminal failure on late delivered event, no implicit unsuppression. No invented provider signature: concrete verified provider/auth scheme and durable ingestion land before public route. Bounces/complaints suppress later messages to the same recipient hash until separately reviewed reconciliation; no auto-resend button shipped.

## Owner UI contract (read-only data ready before sender)

`ReadOutboundMail::forEvent(User,int eventId,array filters=[]): array`; GET `/admin/api/events/{event}/messages` → `{data:[{id,event_id,template_key,template_version,locale,channel,environment,due_at,status,version,attempt_count,error_code,sent_at,updated_at}],page,per_page,total,last_page,policy:{version,paused}}`. Bounded pagination25/default max50; no payload/token/body/raw provider error/recipient export. Query page integer≥1, clamp to last. Owner event visibility mandatory.

`ReadOutboundMail::warnings(User,array filters=[]): array`; GET `/admin/api/messages/warnings` same pagination, status bounced/complained/delivery_unknown/blocked; event reference/error code and owner-facing status, no claiming delivered from sent/opened. Card can show total and link to event; no tracking pixel/read receipt claim.

`ReadOutboundMail::settings(User): array`; GET `/admin/api/mail/settings` → `{environment:sandbox,enabled:bool,transport_configured:false,allowlist:[owner emails],templates:[{key,locale,version,approved:bool}],activation_required:true}`. Read-only config, no secret keys and no browser editing allow-list, consent or provider. #70 draft copy stays separate until approved versioned renderer is supplied. Owner UI calls these APIs; no provisional UI SQL tables or local fake delivery states.
